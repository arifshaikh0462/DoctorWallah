# 🏥 DoctorWallah (Medical Article Publishing Platform)

A full-stack medical content platform where admin can publish doctor-provided articles about diseases, prevention, and treatments.

---

## 🚀 Features

- 📝 Admin can add, edit, and delete articles  
- 👨‍⚕️ Doctor-based content publishing  
- 🔍 Search functionality  
- 📱 Fully responsive (Mobile + Desktop)  
- 🖼️ Image upload support  
- 🗂️ Category-wise articles  
- 🔐 Secure admin login system  

---

## 🧠 Project Idea

This platform is built to share authentic medical knowledge collected directly from doctors via calls/interviews.  
The admin uploads well-structured articles to educate users about health, diseases, and prevention.
